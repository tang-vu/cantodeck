# Community code of conduct

We want contributors and users to be able to collaborate without harassment.

- Be respectful, specific and constructive when discussing code or user experience.
- Welcome different backgrounds and levels of technical experience.
- Do not harass, threaten, discriminate, reveal private information or post sexual content.
- Critique ideas and implementations without attacking people.

These expectations apply to issues, pull requests and other project spaces. Maintainers may edit or remove inappropriate content, warn participants, or restrict participation for repeated or serious violations. Decisions should be proportionate and may be reconsidered when new information is available.

For a moderation request, contact the maintainer `@tang-vu` in an issue without private details. If the situation requires confidentiality, ask for a private contact channel before sharing sensitive information. Do not publish another person's private information in a report.
